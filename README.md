Hands-on AWS Certified Cloud Practitioner labs for learners building foundational cloud literacy and preparing for the AWS Certified Cloud Practitioner exam. The labs cover AWS account setup, global infrastructure, compute, storage, databases, networking, security, monitoring, pricing, support, architecture basics, and exam-style review.

## How to Use

1. Create or use an AWS account provided by your trainer.
2. Create a working folder named `TGS-2023039183-AWS-CCP-Labs`.
3. Complete the labs in sequence because later labs reuse IAM, VPC, monitoring, and cost-management concepts.
4. Record screenshots and short notes for each lab.
5. Delete paid resources when the lab asks you to clean up.
