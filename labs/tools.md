# Tools Reference

## Required Tools

- AWS account or trainer-provided sandbox account
- Web browser
- PDF viewer or notes application

## Recommended AWS Services and Consoles

- AWS Management Console
- IAM
- CloudTrail
- EC2
- Lambda
- S3
- RDS
- DynamoDB
- VPC
- CloudFront
- Route 53
- CloudWatch
- AWS Budgets
- Cost Explorer
- AWS Pricing Calculator
- AWS Well-Architected Tool

## Cost Safety

- Use trainer-provided accounts where available.
- Prefer Free Tier eligible options.
- Do not create paid resources unless instructed.
- Delete resources at the end of each lab.
- Set a budget alert early in the course.
- Check the Billing and Cost Management dashboard after hands-on labs.

## Learner Tips

- Know what each service is for before memorizing details.
- Learn the difference between AWS responsibility and customer responsibility.
- Compare managed services against self-managed alternatives.
- Focus on use-case matching: compute, storage, database, network, security, billing, and support.
- Keep a weak-topic list for final exam revision.
