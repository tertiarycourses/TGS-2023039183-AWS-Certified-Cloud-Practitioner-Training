# AWS Certified Cloud Practitioner Lab Guide

This folder contains practical labs for TGS-2023039183 - AWS Certified Cloud Practitioner Training.

## Lab Sequence

| Lab | File | Outcome |
| --- | --- | --- |
| 1 | [AWS Account Setup, Console Tour, and Cloud Concepts](lab-01-account-setup-cloud-concepts.md) | A secure learner account setup and notes on AWS global infrastructure and cloud concepts. |
| 2 | [IAM, Security, and Shared Responsibility](lab-02-iam-security-shared-responsibility.md) | IAM identities, MFA, least-privilege policy review, and CloudTrail awareness. |
| 3 | [Compute Services: EC2, Lambda, Containers, and Elasticity](lab-03-compute-ec2-lambda-containers.md) | Compute service comparison and optional free-tier EC2/Lambda practice. |
| 4 | [Storage Services: S3, EBS, EFS, Backup, and Lifecycle](lab-04-storage-s3-ebs-efs-lifecycle.md) | S3 bucket practice, storage class comparison, and lifecycle cleanup awareness. |
| 5 | [Databases and Analytics: RDS, DynamoDB, Redshift, and Athena](lab-05-databases-rds-dynamodb-analytics.md) | Service selection matrix for database and analytics use cases. |
| 6 | [Networking and Content Delivery: VPC, Security Groups, CloudFront, and Route 53](lab-06-networking-vpc-cloudfront-route53.md) | VPC and content delivery concepts with security group and DNS/CDN positioning. |
| 7 | [Monitoring, Pricing, Billing, Budgets, and Support](lab-07-monitoring-pricing-billing-support.md) | Budget alert, pricing estimate, support plan comparison, and monitoring notes. |
| 8 | [Architecture, Migration, Sustainability, and Exam Review](lab-08-architecture-migration-exam-review.md) | Well-Architected review, migration mapping, disaster recovery, and timed exam practice. |
